Type an address. Get a 3D model of the house and its street.

A free add-on (a "skill") for Claude. Give it a US street address and it builds a 3D model you can spin around: the house, the house on each side, the real ground, the street and the trees. All of it is measured from public government laser scans. No coding needed.

Download the skill See the 4 steps

Works with a paid Claude plan (Pro, Max, Team or Enterprise) on claude.ai or the Claude app. Takes about 5 minutes to set up, then about 3 minutes per address.

How to use it, in 4 steps

Steps 1–3 happen once. After that it's only step 4.

  1. 1

    Download the skill

    Click the yellow button to download address-3d-model.zip. Don't unzip it; Claude wants the zip file as it is.

    Download address-3d-model.zip
  2. 2

    Add it to Claude

    In Claude, open Customize → Skills, choose Upload a skill, and pick the zip you just downloaded. The skill turns on by itself.

    If you don't see Skills, turn on Code execution and file creation in Settings → Capabilities first. Claude's help page on skills.

  3. 3

    Let Claude reach the map data

    Claude runs the skill in a locked-down workspace that can't reach most websites. The skill needs to download public maps and laser scans, so allow that once:

    Pro or Max plan (personal account)In Settings → Capabilities, allow network access and add the websites below. On the Free plan Claude can only reach software packages, so this skill can't run there.
    Team or Enterprise plan (work or school)Only an owner of your organization can change this. Send them the list below and ask them to add it under Organization settings → Capabilities → Code execution.

    Websites the skill uses (all public, no accounts):

    • geocoding.geo.census.gov
    • nominatim.openstreetmap.org
    • s3-us-west-2.amazonaws.com
    • elevation.nationalmap.gov
    • overpass-api.de
    • services.arcgis.com
    • mdgeodata.md.gov

    GitHub and Python packages, which the skill also uses, are usually allowed already. Claude's help page on network access.

  4. 4

    Ask for a model

    Start a new chat and type something like this, with your own address:

    Make a 3D model of 1600 Pennsylvania Ave NW, Washington, DC 20500

    Claude works for 2–5 minutes, then gives you a link to the model. Drag to spin it, scroll to zoom, and tap a house to see its measurements. The link is private to you until you share it.

What you get

The shapes are measured; the details are filled in. The model page says the same.

Measured

From public data

  • Which house is yours, from the U.S. DOT National Address Database
  • Where each house stands and which way it faces
  • Footprint size, wall height and roof height
  • Roof shape (gable, hip or flat), steepness and cross gables
  • The real slope of the ground, to within about a foot
  • Trees, where they are and how tall
  • The street, from OpenStreetMap
Filled in

Generated to look right

  • Windows, doors and garage doors
  • Siding colors
  • Shrubs, decks and driveway shape
  • Small roof details such as dormers and porches, which are left out

If something goes wrong

Claude tells you what happened in plain words. These are the usual cases.

Claude says some websites are blocked
Step 3 isn't done yet, or your organization hasn't added the websites. Claude lists the ones it couldn't reach. Turn on network access, or send that list to your organization's owner, then ask again.
Claude says there's no laser-scan data for the address
The skill uses the U.S. Geological Survey's 3D Elevation Program, which covers most of the country but not every place yet. Very rural areas, some territories and a few cities have no data or only old data.
Only one neighbor (or none) appears
That's normal for corner lots, houses next to an empty lot or a park, and rural homes. The skill only shows houses it actually found in the scan.
The wrong house is highlighted
Where the National Address Database has your address, the skill finds the exact house. Where it doesn't, it falls back to a point on the street and the model says "approximate" in its notes. Then tell Claude, for example, "it's the house to the left", and it will move the highlight.
The house faces the wrong way, or the roof looks off
Older or sparser scans give rougher roofs, and trees over a roof can confuse it. Ask Claude to fix it in plain words, for example "the front faces the other street" or "make the roof a hip roof". It can edit the model without downloading again.
Is my address shared with anyone?
To find the address on a map, the skill sends it to the U.S. Census Bureau's address lookup (or OpenStreetMap's, if that fails), then looks up the house number near that spot in the U.S. DOT National Address Database. The scans and maps are then downloaded by location. Nothing is looked up about who lives there. The finished model is private to your Claude account unless you share its link.
Does it work outside the US?
Not yet. It relies on U.S. government laser scans and terrain data.

Comfortable with a terminal?

The same skill works in Claude Code, which runs on your own computer with your normal internet, so step 3 isn't needed. Skills in your Claude account appear in Claude Code automatically. To add it by hand:

git clone https://github.com/lagostimgomes/address-3d-model
mkdir -p ~/.claude/skills
cp -r address-3d-model/skill/address-3d-model ~/.claude/skills/
# then, in Claude Code:  make a 3D model of <address>

Or run the pipeline yourself, without Claude:

cd address-3d-model
pip install -r requirements.txt
python run.py "1600 Pennsylvania Ave NW, Washington, DC 20500"
# writes sites/<address>/index.html
